# Release Notes - v1.0.0

## 🍬 Bubblegum Theme - Initial Release

A sweet pink and purple dark theme for Visual Studio Code with bubblegum aesthetics.

### ✨ Features

- **Eye-friendly Dark Mode**: Deep purple blacks that are easy on the eyes
- **Vibrant Pink & Purple**: Beautiful bubblegum-inspired accent colors
- **Consistent UI**: Harmonious colors across editor, sidebar, and terminal
- **Optimized Syntax Highlighting**: Clear and readable syntax colors

### 🎨 Color Palette

- **Backgrounds**: `#1a1226`, `#16101f`, `#120d19`
- **Accents**: `#ff8ec4`, `#ff6b9d`, `#ad5599`
- **Foreground**: `#ffd4e8`
- **Syntax Colors**:
  - Strings: Mint green `#a8e6cf`
  - Keywords: Pink `#ff8ec4`
  - Functions: Lavender `#c76eb3`
  - Numbers: Peach `#ffd3a5`
  - Types: Sky blue `#a8d8ff`

### 📦 Installation

**From VS Code Marketplace:**
1. Open Extensions (`Ctrl+Shift+X`)
2. Search "Bubblegum Theme"
3. Click Install
4. Select theme: `Ctrl+K Ctrl+T` → Bubblegum

**Manual Installation:**
Download `bubblegum-theme-1.0.0.vsix` from this release, then:
1. VS Code → Extensions → `...` → Install from VSIX
