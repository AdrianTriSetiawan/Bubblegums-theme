About This Theme

The Bubblegums theme features a delightful color palette inspired by classic bubble gum. It combines playful pinks, purples, and soft blues to create a fun and energetic aesthetic.

Features:

  • Vibrant pink primary colors
  • Soft, complementary accent colors
  • Smooth transitions and hover effects
  • Rounded corners and soft shadows
  • CSS custom properties for easy customization
